# Cargo Website

Учебный frontend-проект: вёрстка сайта логистической компании по готовому дизайну.

## Что реализовано

- семантическая структура страницы: header, navigation, main, sections и footer;
- главный экран со слайдером и переключателями;
- многошаговая форма расчёта стоимости доставки;
- форма обратной связи и модальное окно;
- блок вопросов и ответов с раскрывающимися элементами;
- карточки услуг, преимущества, информационные секции и футер;
- подключение локальных шрифтов, растровых изображений и SVG-иконок.

Интерактивные элементы реализованы средствами HTML и CSS: через состояния `:checked`, переходы и CSS-анимации.

## Стек

- HTML5
- CSS3
- Flexbox
- CSS Grid Layout
- SVG

## Структура

```text
index.html       Основная страница
style.css        Стили интерфейса
image/           Изображения и SVG-иконки
fonts/           Локальные шрифты
```
